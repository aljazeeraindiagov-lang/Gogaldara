# The Gogaldara
**Designed & Curated by Shahid Mir**
*A complete, responsive multi-page web sanctuary celebrating Gogaldara, Tangmarg, Baramulla, Kashmir.*

---

## 🌟 Overview
**The Gogaldara** is an authentic, multi-page website built with semantic HTML5, modern CSS3, Tailwind CSS responsiveness, and pure vanilla JavaScript. It is designed to run seamlessly in **VS Code with Live Server** (no frameworks or build step needed) as well as within modern bundlers like Vite.

### ✨ Key Features
- **10 Complete Pages**:
  1. `index.html` - Full-screen hero image slider, welcome message from curator Shahid Mir, key facts counter, featured places, best seasons guide, and call to action.
  2. `about.html` - Historical pastoral roots, Gujjar heritage, Tangmarg tehsil geography, Pir Panjal elevation, and mountain flora/fauna.
  3. `gallery.html` - High-resolution responsive photo grid with filter buttons and a click-to-zoom modal lightbox with keyboard navigation.
  4. `explore.html` - Comprehensive travel guide to Chill Point (35-ft icicles), Tangmarg town, Baba Reshi shrine, Drung cascade, authentic Kashmiri cuisine (Kahwa, Wazwan, Makki ki Roti), road routes from Srinagar Airport, and an interactive OpenStreetMap embed.
  5. `menu.html` - Full site directory categorizing all 10 pages and interactive sections.
  6. `login.html` - Validated traveler authentication form with show/hide password toggle, remember-me check, and quick-fill demo credentials.
  7. `signup.html` - Registration form with real-time password strength meter (animated bar + 4-rule checklist) and terms agreement.
  8. `settings.html` - Dark/Light mode toggle, font size scaler (Compact 14px, Standard 16px, Comfortable 18px), language selector (English, Urdu, Kashmiri, Hindi), and notification preferences.
  9. `help.html` - Searchable interactive FAQ accordion and direct Community Desk contact form.
  10. `feedback.html` - Interactive 5-star rating selector, category filter, validation, and real-time community reviews list.
- **Global Sticky Header**: Glassmorphism blur, brand logo, search bar with live auto-suggestions dropdown, notification bell with unread badge & sample alerts, theme toggle button, and mobile slide-in drawer.
- **Nature-Inspired Palette**: Deep Kashmiri Pine Green (`#143828`), Himalayan Sky Blue (`#0284c7`), Crisp Snow White, and Warm Kashmiri Saffron/Amber (`#d97706`).
- **Zero-Build Live Server Ready**: Uses pure vanilla JavaScript and Tailwind CSS CDN so it opens directly in VS Code without `npm install` or any build commands.

## 🚀 How to Run in VS Code (No Build Step Required)
1. **Open the Project**: Open the project folder in **Visual Studio Code**.
2. **Install Live Server Extension**: If not already installed, press `Ctrl+Shift+X` (or `Cmd+Shift+X` on Mac), search for **Live Server** (by *Ritwick Dey*), and click **Install**.
3. **Launch the Site**:
   - Right-click `index.html` in the file explorer.
   - Click **"Open with Live Server"** (or click **"Go Live"** in the VS Code bottom status bar).
   - Your default web browser will open `http://127.0.0.1:5500/index.html`.
4. **Enjoy**: Navigate through all 10 pages, toggle dark mode, search for attractions, test the lightbox, and submit reviews!

## 🏔️ Research Facts Behind The Gogaldara
- **Location**: Gogaldara village is located in **Tangmarg tehsil of Baramulla district**, North Kashmir.
- **Distance**: Approximately **13 km from Tangmarg town**, ~40 km from Baramulla Railway Station, and ~60 km from Srinagar International Airport.
- **Chill Point**: Gogaldara's signature winter phenomenon where sub-zero temperatures freeze mountainside seepages into massive natural **35-foot vertical icicle cascades**.
- **Seasons**: Peak winter (Dec–Feb) for snow and icicles; Spring & Summer (Mar–Aug) for lush wildflower meadows and deodar pine treks.
- **Culture**: Traditional Gujjar-Bakrawal pastoral lineage, wood-fired hearths (Bukhari), earthen willow-worked charcoal heaters (Kangri), hot saffron Kahwa, and warm rural Kashmiri hospitality.
